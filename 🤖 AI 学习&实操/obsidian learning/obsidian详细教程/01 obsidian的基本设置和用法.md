## Obsidian 基础用法总结

### 1. 创建或打开资料库

Obsidian 的资料库叫 Vault，可以理解为一个专门存放笔记的文件夹。

基本操作：

- 新建一个 Vault；
- 选择保存位置；
- 在 Vault 中创建笔记、文件夹和附件；
- 以后所有内容都围绕这个资料库管理。

可以把它理解为：

> Vault = 你的个人知识库文件夹。

### 2. 创建和管理笔记

在资料库中可以新建 Markdown 笔记。

常见操作：

- 新建笔记；
- 修改笔记名称；
- 创建文件夹；
- 将笔记移动到不同文件夹；
- 删除或恢复笔记；
- 在多个笔记之间切换。

建议文件夹不要一开始设计得太复杂，先按照自己的学习、工作或项目分类即可。

### 3. 认识 Obsidian 界面

Obsidian 的界面主要可以分为：

- 左侧：功能栏、文件列表和文件夹；
- 中间：当前正在编辑的笔记；
- 右侧：大纲、反向链接、标签等辅助信息；
- 顶部：标签页、搜索和常用操作；
- 底部或状态栏：字数、编辑状态等信息。

最重要的是中间的笔记编辑区。不要一开始被各种按钮和面板分散注意力，先学会正常创建和编辑笔记。

### 4. 使用 Markdown 写笔记

Obsidian 使用 Markdown 编辑文本。

最常用的写法：

```
# 一级标题
## 二级标题

- 无序列表
1. 有序列表

**加粗**
*斜体*
`代码`

> 引用
```

Markdown 的好处是：文字和结构同时保存，格式简单，文件也容易迁移。

### 5. 创建链接

Obsidian 的核心价值之一是连接笔记。

输入：

```
[[笔记名称]]
```

就可以链接到另一篇笔记。

例如：

```
[[金融分析]]
[[公司商业模式]]
[[现金流]]
```

这样做的意义是：笔记不再是孤立的文件，而是可以逐渐形成知识网络。

### 6. 搜索和查找内容

当笔记数量增加后，可以通过搜索快速查找：

- 笔记标题；
- 正文关键词；
- 文件夹；
- 标签；
- 链接关系。

建议笔记标题尽量清楚，不要使用“新建笔记 1”“资料整理”这类过于模糊的名称。

### 7. 进行基础设置

设置中通常可以调整：

- 界面主题；
- 字体大小；
- 编辑器显示方式；
- 新建笔记的默认位置；
- 附件保存位置；
- 文件与链接的处理方式；
- 快捷键；
- 核心插件和第三方插件。

但设置的重点不是“把界面装修得很漂亮”，而是让它更适合自己的工作流程。

### 8. 插件要按需使用

Obsidian 有核心插件和第三方插件。

插件可以增加：

- 日历；
- 看板；
- 思维导图；
- 表格；
- 任务管理；
- 数据查询等功能。

但基础阶段不建议一开始安装很多插件。更合理的顺序是：

> 先会创建笔记 → 再会组织笔记 → 再建立链接 → 最后按需求增加插件。

## 最简单的使用流程

```
创建 Vault
↓
新建笔记
↓
用 Markdown 写内容
↓
按需要建立文件夹
↓
用 [[双向链接]] 连接相关笔记
↓
用搜索和反向链接查找知识
↓
遇到明确需求后再安装插件
```

## 最核心的理解

Obsidian 不是单纯的收藏夹，也不是必须安装很多插件的软件。

它最基础、最重要的用法只有三件事：

1. 生产自己的内容；
2. 管理自己的笔记；
3. 把相关知识连接起来。

如果只收藏资料而不理解、不输出、不建立连接，Obsidian 最后也可能变成一个“电子垃圾桶”。
